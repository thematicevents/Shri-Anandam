# 🏛️ Shri Anandam Luxury Resort Portal

A high-end, responsive web application built for **Shri Anandam (Shri Maheshwari Jankalyan Trust)**, Indore. This portal showcases 86,000 sq. ft. of luxury event spaces and premium accommodations.

## ✨ Key Features
- **360° Virtual Tour:** Interactive room previews using React State management.
- **Smart Inquiry System:** Serverless lead capture via Google Apps Script & Google Sheets.
- **Luxury UI:** Crafted with Cinzel & Montserrat typography and AOS animations.
- **Glassmorphic Components:** Modern, blurred-background modals for status updates.
- **SEO Optimized:** Custom sitemap, meta tags, and favicon for Indore local search.

## 🛠️ Tech Stack
- **Frontend:** React.js, FontAwesome, AOS (Animate on Scroll)
- **Database/Backend:** Google Sheets API (via Apps Script)
- **Styling:** CSS-in-JS & Global CSS for smooth scrolling.
